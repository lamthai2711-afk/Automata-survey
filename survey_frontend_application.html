Module 4: Post-Intervention Knowledge Test

Suggested time limit: 15 minutes • Total: 20 points

Part A: Retention Test (6 Points)

Retrieve formal definitions & rules

Part B: Near-Transfer Test (8 Points)

Apply algorithm to a novel automaton

Problem T1 (8 points): Consider an NFA over alphabet $\Sigma = \{0, 1\}$ with state set $Q = \{A, B, C\}$, initial state $A$, and accept state $C$.

Transitions:
• $\delta(A, \varepsilon) = \{B\}$; $\delta(A, 0) = \{A\}$
• $\delta(B, 1) = \{C\}$; $\delta(B, \varepsilon) = \emptyset$
• $\delta(C, 0) = \{C\}$; $\delta(C, 1) = \{B\}$

Tasks to answer in your derivation:

  • (2 points) Determine the formal initial state $q_0'$ of the equivalent DFA using the $\varepsilon\text{-closure}$ rule.
  • (3 points) Compute the transition from this initial state on input symbol '0', i.e., calculate $\delta'(q_0', 0)$.
  • (3 points) List all generated states of the resulting DFA and identify which of them is/are the accepting state(s).

Part C: Far-Transfer Test (6 Points)

Conceptual generalization to system optimization

Problem T2 (6 points): A software engineer is designing an input verification parser for a security gateway. The state machine contains 4 states:

• $q_0$ (Start): Awaiting valid prefix.
• $q_1$: Valid alphabetic prefix registered.
• $q_2$: Valid numeric prefix registered.
• $q_3$ (Accept): Valid credential pattern of Class A.
• $q_4$ (Accept): Valid credential pattern of Class B.
From $q_3$, any subsequent character transitions back to $q_3$. From $q_4$, any subsequent character transitions back to $q_4$. In the system backend, both $q_3$ and $q_4$ trigger the exact same downstream access permissions.

Tasks to address:

  • (3 points) Based on the Equivalence Partitioning principle (Moore / Hopcroft minimization), can states $q_3$ and $q_4$ be collapsed into a single equivalent state? Explain your reasoning using the concept of the initial partition $P_0$ and transition signatures.
  • (3 points) What concrete benefits does collapsing these equivalent states provide regarding memory footprint and execution latency in an embedded microcontroller?
