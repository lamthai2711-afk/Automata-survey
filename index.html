Question 2.1 (Power Set Property): Let $A = \{q_0, q_1\}$ be a set containing 2 distinct state labels. What is the total number of elements in its power set $\mathcal{P}(A)$? *

Question 2.2 (Formal Automaton Specification): In the formal 5-tuple definition of a Deterministic Finite Automaton $M = (Q, \Sigma, \delta, q_0, F)$, what mathematical object does the symbol $\delta$ denote? *

Question 2.3 (Operational Distinction): Which statement correctly describes the operational distinction between an NFA and a DFA? *

Question 2.4 (Execution Tracing): Consider an automaton with state A (start) and state B (accept). Reading '0' loops on A; reading '1' transitions from A to B. From B, reading either '0' or '1' transitions back to A. Which of the following strings is accepted? *

Question 2.5 (Empty Closure Reachability): In an NFA, suppose there is an $\varepsilon$-transition from state $q_0$ to $q_1$, and an $\varepsilon$-transition from state $q_1$ to $q_2$. Which set constitutes the $\varepsilon$-closure of $q_0$ (denoted $\text{E-set}(q_0)$)? *
